# Travailler sur FabCore

**Phase active : [POC](docs/POC.md).** Lire le jalon concerné avant de chercher dans le code.

- [POC](docs/POC.md) · état actuel, recette et prochain jalon.
- [MVP](docs/MVP.md) · périmètre de la bêta et agent local.
- [Développement complet](docs/FULL-DEVELOPPEMENT.md) · évolutions après le MVP.

Pour limiter le contexte, ouvrir seulement le fichier de la phase concernée, puis les tickets et les fichiers nécessaires. Utiliser `rg` pour cibler les lectures. Le [guide POC](poc/README.md) documente l’exploitation et le [guide des connecteurs](poc/CONNECTORS.md) le contrat technique.

Chaque jalon a sa propre PR. Dans la PR, actualiser le fichier de phase avec le lien vers le ticket ou la PR et la validation effectuée. Distinguer fusion, déploiement et essai sur matériel. Garder les détails techniques dans la PR et les instructions utilisateur dans le README ou le guide d’exploitation.
