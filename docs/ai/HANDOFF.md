# Modèle de relais — à remplir dans la PR ou le ticket

- Jalon / objectif :
- Branche, commit et modifications non commitées à préserver :
- Décisions acquises / contraintes :
- Résultat actuel et fichiers/symboles pertinents :
- Vérifications réellement exécutées et résultat :
- Limites, erreurs ou blocages :
- Première action suivante :

Cible : 200 à 400 mots, liens et chemins plutôt que copies de code/logs. Aucun secret. Ce fichier est un modèle ; ne pas y accumuler un journal de toutes les sessions.
